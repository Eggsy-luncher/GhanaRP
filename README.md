# Ghana RP

![Version](https://img.shields.io/badge/version-0.0.1-blue)

## Developed by
**Mordecai Studios**

## About

Ghana RP is an open-world multiplayer roleplay game inspired by Ghana. Players can become police officers, firefighters, paramedics, business owners, taxi drivers, mechanics, and much more.

## Features

- Multiplayer
- Character Creation
- Open World
- Economy
- Housing
- Vehicles
- Jobs
- Police System
- Fire Service
- EMS
- Banking
- Mobile Money

## Technology

- Unity 6
- C#
- Mirror Networking
- GitHub
